## Overview

This repository contains lab work for **LAB 3** of the
Computer Fundamentals & Career Pathways (CSE103) course at
**K.R. Mangalam University**, Gurugram.

**Author:** Ashwani Singh

The lab covers Git repository management, GitHub collaboration,
Markdown documentation, and REST API interaction.

## Repository Structure

| File | Purpose |
|------|---------|
| README.md | Project overview and instructions |
| MARKDOWN_GUIDE.md | Markdown syntax reference and examples |
| CHANGELOG.md | Version history |
| main.py | Primary Python script |
| .gitignore | Files excluded from Git tracking |

## Skills Demonstrated

- Git initialisation and repository management
- Meaningful commits
- Working with a GitHub remote
- Markdown headings, lists, tables, and code blocks

## How to Run

### Requirements

- Git
- Python 3

### Steps

1. Clone the repository.
2. Navigate to the project folder.
3. Run the Python script.

```bash
git clone https://github.com/ashu2k71-bit/cse103-lab-LAB3.git
cd cse103-lab-LAB3
python3 main.py
```
